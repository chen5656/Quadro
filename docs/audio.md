# Audio

Every sound the game makes is generated by `scripts/audio/build.mjs` and
committed under `public/audio/`. Nothing is licensed from a third party, so
there is no attribution to carry and no track to re-clear if the game is
rebranded again.

```bash
npm run audio:build   # needs ffmpeg on PATH
```

## What exists

| File | When it plays |
| --- | --- |
| `sfx/select.mp3` | A colour is picked up from a display or the centre. Pitched down a tone when the same pick is put back. |
| `sfx/place.mp3` | The tile lands. Pitched down onto the penalty row, and down and quieter for the opponent's moves. |
| `sfx/invalid.mp3` | A tap that cannot do anything, but only on the player's own turn. |
| `sfx/score.mp3` | One tile reaching the wall during settlement. The bell climbs with that tile's own score. |
| `sfx/penalty.mp3` | The penalty row emptying. |
| `sfx/bonus.mp3` | An end-of-game row, column or colour line. |
| `sfx/round.mp3` | A round turning over — suppressed on the last one, which has its own sting. |
| `sfx/win.mp3`, `sfx/lose.mp3` | The result, after the bonus lines have finished. |
| `sfx/ui.mp3` | Buttons and toggles. |
| `music/menu.mp3` | Home, leaderboards, results — anything that is not a board. |
| `music/game.mp3` | The Daily, Practice and the tutorial. Darker and sparser. |

Both beds loop seamlessly: the renderer runs six seconds past the loop point and
folds the tail back over the head (`crossfadeLoop`).

## Wiring

`src/audio/audio.ts` is a module-level singleton rather than a hook, because
most of what makes noise is not a component — the scoring bells are fired from
inside `animateSettlement`, the move sounds from `useGameSession`. Anything that
can import it can call `sfx(id)`.

- Nothing is fetched until a sound is actually wanted.
- Nothing can start before the first pointer or key event; the bed is armed and
  started on that gesture, because browsers refuse autoplay.
- Where Web Audio is missing or blocked, every call is a silent no-op. That is
  also what happens under jsdom, so the test suite needs no audio stubs.
- The same one-shot twice inside 35 ms collapses into one, so a burst of
  simultaneous events cannot phase into a slap.

## Settings

Two independent switches, in the ⚙ menu and remembered in localStorage
(`nodra.v1.soundMusic`, `nodra.v1.soundSfx`), both on by default:

- **Music** — the looping bed.
- **Sound effects** — every one-shot.

Both off is silence; turning off only effects leaves the music playing, which is
the arrangement the request asked for. "Mute all" sets both at once.

## Delivery

The mp3s are deliberately *outside* the service worker's precache — a player who
never turns the sound on should not pay 1.5 MB to install the game. A
`CacheFirst` runtime rule caches them the first time they are heard, which is
enough to keep an offline Practice game sounding like an online one.
`public/_headers` serves `/audio/*` immutable for a year; a new sound design
ships as a new file rather than an edit in place.

## Replacing a track

The loader only cares about the path, so a hand-picked track can be dropped
straight in as `public/audio/music/menu.mp3` or `game.mp3`. It should loop
cleanly and be mastered quiet — the bed plays at 0.34 gain and is meant to sit
under twenty minutes of thinking. Anything licensed rather than generated needs
its attribution recorded here.
