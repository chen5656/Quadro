# Audio

Every sound the game makes is generated by `scripts/audio/build.mjs` and
committed under `public/audio/`, with two exceptions: both music beds that play
over a board are licensed tracks. See [Credits](#credits) for what has to be
carried.

```bash
npm run audio:build   # needs ffmpeg on PATH
```

## What exists

| File | When it plays |
| --- | --- |
| `sfx/select.mp3` | A colour is picked up from a display or the centre. Pitched down a tone when the same pick is put back. |
| `sfx/place.mp3` | The tile lands. Pitched down onto the penalty row, and down and quieter for the opponent's moves. |
| `sfx/invalid.mp3` | A tap that cannot do anything, but only on the player's own turn. |
| `sfx/score.mp3` | One tile reaching the wall during settlement. The bell climbs with that tile's own score. |
| `sfx/penalty.mp3` | The penalty row emptying. |
| `sfx/bonus.mp3` | An end-of-game row, column or colour line. |
| `sfx/round.mp3` | A round turning over — suppressed on the last one, which has its own sting. |
| `sfx/win.mp3`, `sfx/lose.mp3` | The result, after the bonus lines have finished. |
| `sfx/ui.mp3` | Buttons and toggles. |
| `music/menu.mp3` | Home, leaderboards, results — anything that is not a board. |
| `music/practice.mp3` | Practice and the tutorial. One 37 s guitar loop, the whole way through — no phases. Licensed. |
| `music/daily.mp3` | The Daily only, one looping cue (below). Licensed. |

`menu.mp3` is generated and loops seamlessly in the file itself: the renderer
runs six seconds past the loop point and folds the tail back over the head
(`crossfadeLoop`). The two licensed beds are joined in the player instead.

`scripts/audio/build.mjs` still knows how to render a `game.mp3` bed, and the
committed `public/audio/music/game.mp3` is what it last produced. Nothing loads
it any more — the `game` cue points at `practice.mp3`.

## Joining a loop

Every looping cue is played as overlapping passes rather than one source with
`loop = true`, because a plain loop jumps from `loopEnd` to `loopStart` and any
seam there is audible as a click. Each pass fades in while the previous fades
out on an equal-power (sin/cos) curve, so two correlated copies of the same
music do not dip in the middle of the join.

The overlap is `MUSIC_XFADE` (1.5 s) unless a cue sets its own `xfade`. Longer
hides an arbitrary cut out of a longer recording; shorter costs less of the
region, since the overlap is time never heard at full level. `practice.mp3` was
authored as a loop and its ends already meet, so it uses 0.8 s — enough to
soften the join and no more.

## The Daily's cue

`daily.mp3` is a 27-second region (27 s–54 s of the source recording) that loops
for the whole attempt — first round through the final scoring — under the single
`daily` cue. The cut points are not seamless, so the loop seam is crossfaded in
the player at the full `MUSIC_XFADE`, and the bed fades in over 1.4 s when it
starts and out over 0.6 s when it is replaced.

## Wiring

`src/audio/audio.ts` is a module-level singleton rather than a hook, because
most of what makes noise is not a component — the scoring bells are fired from
inside `animateSettlement`, the move sounds from `useGameSession`. Anything that
can import it can call `sfx(id)`.

- Nothing is fetched until a sound is actually wanted.
- Nothing can start before the first pointer or key event; the bed is armed and
  started on that gesture, because browsers refuse autoplay.
- Where Web Audio is missing or blocked, every call is a silent no-op. That is
  also what happens under jsdom, so the test suite needs no audio stubs.
- The same one-shot twice inside 35 ms collapses into one, so a burst of
  simultaneous events cannot phase into a slap.

## Settings

Two independent switches, in the ⚙ menu and remembered in localStorage
(`nodra.v1.soundMusic`, `nodra.v1.soundSfx`), both on by default:

- **Music** — the looping bed.
- **Sound effects** — every one-shot.

Both off is silence; turning off only effects leaves the music playing, which is
the arrangement the request asked for. "Mute all" sets both at once.

## Delivery

The mp3s are deliberately *outside* the service worker's precache — a player who
never turns the sound on should not pay 1.5 MB to install the game. A
`CacheFirst` runtime rule caches them the first time they are heard, which is
enough to keep an offline Practice game sounding like an online one.
`public/_headers` serves `/audio/*` immutable for a year; a new sound design
ships as a new file rather than an edit in place.

## Replacing a track

The loader only cares about the path, so a hand-picked track can be dropped
straight in as `public/audio/music/menu.mp3`, `practice.mp3` or `daily.mp3`. It
should loop cleanly and be mastered quiet — the bed plays at 0.34 gain and is
meant to sit under twenty minutes of thinking. A replacement for `daily.mp3`
is trimmed to its loop region before it is dropped in; adjust `MUSIC_CUES` if
the region does not start at 0.
Anything licensed rather than generated needs its attribution recorded under
[Credits](#credits), and the entry in the README kept in step.

## Silence, and why

Three things have to be true before a browser makes a sound, and each has bitten
this build once:

- **A gesture.** The context is created suspended and armed on first load; the
  first pointer or key event resumes it and starts the bed.
- **A gesture the browser still believes in.** iOS only honours a `resume()`
  issued synchronously inside the handler, so `play()` kicks the resume before
  it awaits the fetch. Awaiting first put it on the far side of that boundary
  and the sound was dropped.
- **A phone that is not muted.** iOS silences Web Audio when the ring/silent
  switch is off. `navigator.audioSession.type = 'playback'` (Safari 17+) opts
  out; below that, nothing can, so the settings menu says so on iOS rather than
  letting a muted phone read as a broken game.

The bed a route asked for is remembered in `requested`, separately from what is
actually playing. Turning music off and on again used to land in silence: the
stop had cleared the current track, the route had not changed, and so nothing
re-asked for it.
